# Pixel Reframe Lab

画像の一部分を帯として選び、伸縮、削除、反復、鏡面化、引き伸ばし、位置ずらしを行う軽量なブラウザ画像再構成ツールです。リポジトリ名は既存URLを維持するため `roof-stretch-editor` のままですが、用途は屋根に限定していません。

公開先

https://abcderp2.github.io/roof-stretch-editor/

## 何ができるか

### 帯の局所変形

縦または横の帯を選び、次の処理を行えます。

1. 伸ばす
2. 縮める
3. 繰り返す
4. 鏡面反復
5. 1列または1行を引き伸ばす
6. 帯を削除する
7. 帯だけを直角方向へ循環移動する

空、壁、床、布、背景、模様などを利用し、被写体そのものを拡大せずに画像比率や構図を変える用途を想定しています。

### 余白生成

上、右、下、左へ別々の量の余白を追加できます。生成方式は次の5種類です。

1. 鏡面で延長
2. 画像を反復
3. 端の色を引き延ばす
4. 単色
5. 透明

### 画像全体の調整

左右反転、上下反転、90度単位の回転、4辺からの切り抜きに対応します。

### やり直しと再利用

最大30段階の元に戻す、やり直すに対応します。編集設定は画像を含まないJSONレシピとして保存し、別の画像へ再利用できます。設定はブラウザ内にも保存されますが、読み込んだ画像は保存しません。

### 入力と保存

ファイル選択、ドラッグ操作、クリップボードからの画像貼り付けに対応します。PNG、JPEG、WebPで保存でき、対応端末では共有メニューも利用できます。Canvasで再生成するため、位置情報などの画像付加情報は保存画像へ引き継ぎません。

## 一般的なデザインツールとの違い

文字、図形、テンプレート、素材販売、共同編集、クラウド保存は扱いません。画像の帯構造と外周だけを再構成する用途へ絞っています。Canvaなどの総合デザインツールを置き換えるものではありません。

## 無料で維持できる構成

外部API、外部JavaScript、外部CSS、外部フォント、解析、広告、アカウント、サーバー処理を使用しません。HTML、CSS、JavaScriptだけで動作し、GitHub Pagesで無料公開できます。

Node.jsは開発時の検査だけに使用します。利用者がサイトを使うためにNode.jsやビルド処理は必要ありません。依存パッケージと `package.json` はありません。

役割は次のように分離しています。

`core.js` は設定の正規化、寸法計算、画像ヘッダー検査、レシピ処理を担当します。

`render.js` はCanvas描画だけを担当します。

`app.js` は画面操作、履歴、ファイル読込、保存、共有を担当します。

## 使い方

1. 画像を選択、ドロップ、または貼り付けます。
2. 目的別ボタンを選ぶか、帯の方向と変形方法を指定します。
3. 範囲表示へ切り替え、白い枠を指またはマウスで動かします。
4. 必要に応じて余白、回転、反転、切り抜きを調整します。
5. 押して元画像で差を確認します。
6. 保存形式と最大寸法を選び、画像を保存します。

パソコンでは `Ctrl` または `Command` と `Z` で元に戻し、`Shift` と `Z` または `Y` でやり直せます。`Ctrl` または `Command` と `S` で保存できます。

## 低性能端末への配慮

端末のメモリ、CPUコア数、画面幅をブラウザが公開している範囲で確認し、プレビュー解像度と保存時の画素数上限を自動調整します。

省メモリ端末ではプレビューを最大760px、保存処理を最大1200万画素に抑えます。標準端末では最大1800万画素、高精細端末では最大2400万画素です。

入力上限は次の通りです。

1. ファイル容量18MB以下
2. 元画像2000万画素以下
3. 元画像の縦横10000px以下
4. 出力画像の縦横10000px以下

大きな画像を処理すると、上限内でも端末やブラウザによってはメモリ不足になる場合があります。その場合は保存最大寸法を下げてください。

## セキュリティとプライバシー

画像のMIME表示だけを信用せず、JPEG、PNG、WebPの実データ署名と画像寸法を復号前に確認します。表示形式と実データが一致しないファイル、空ファイル、上限超過ファイルを拒否します。

Content Security Policyで外部通信、埋め込み、オブジェクト、フォーム送信を制限しています。`eval`、`innerHTML`による動的挿入、外部ネットワーク要求を使用しません。

画像はブラウザのメモリ内で処理します。読み込んだ画像をLocalStorageへ保存しません。設定だけを保存します。詳細は `SECURITY.md` を確認してください。

## 品質管理

特定企業の非公開な社内基準への適合や認証を示すものではありません。公開Webアプリで一般的に使われる次の考え方を、追加課金なしで維持できる範囲へ落とし込んでいます。

1. 外部依存と権限を最小化する
2. 入力を信用せず検査する
3. 役割ごとにファイルを分ける
4. 寸法計算を単体テストする
5. DOM参照とCSPを自動検査する
6. 変更を作業ブランチとプルリクエストへ分離する
7. 1回のsquash mergeで戻しやすくする
8. README、セキュリティ文書、コードを同じ変更で更新する

GitHub ActionsではJavaScript構文、12件のコアテスト、20件の描画パイプライン検査、DOM参照、危険API、外部通信設定を検査します。

## 開発時の確認

Node.js 22以降で次を実行します。

```text
node --check core.js
node --check render.js
node --check app.js
node tests/core.test.js
node tests/render.test.js
node tests/static.test.js
```

ブラウザでは最低限、次を確認します。

1. JPEG、PNG、WebPを読み込める
2. 7種類の帯変形が縦横で動く
3. 白い枠をタッチで移動できる
4. 5種類の余白生成が動く
5. 回転、反転、切り抜きが動く
6. 元に戻す、やり直すが動く
7. JSONレシピを保存、読込できる
8. PNG、JPEG、WebPを保存できる
9. 280px幅から大画面まで横にはみ出さない
10. 外部通信が発生しない

## 変更を戻す

変更は作業ブランチからsquash mergeします。問題が見つかった場合はGitHubの対象プルリクエストからRevertを作成すると、関連変更を1回で戻せます。mainを直接編集するより安全です。
